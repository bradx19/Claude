The value thread

Each session should feel like the next step of one story: your team gets time back, and keeps what we build. Three habits make that visible every week.

  1. Open every session with "time back." Ask each person what AI did for them since last week and roughly how many minutes it saved. Keep a running total. Session 4 ends with the number.
  2. Close every session with "you keep." Name the file or tool they walk away with, the same "You keep" line from the program overview.
  3. Point forward. End by saying how today's piece gets used next week. Each session builds on the last.

Reference for the tool spotlights

Which Claude tool for which job

Each session has a 10-minute tool spotlight. Use this page to keep the comparisons consistent. The simple rule to teach: start in chat, move to a Project when you repeat yourself, and let Brad build a skill or tool when the team does it every week.

Chat

Best for: one-off questions and drafts

Fast and flexible. Forgets your setup between conversations unless you paste it in again.

Projects

Best for: anything you do again and again

A workspace with saved files and instructions, like the voice file and listing details. Every chat inside it starts with that context. Can be shared with the team.

Skills

Best for: a recipe the team repeats

Saved step-by-step instructions Claude follows the same way every time, such as brand voice or the listing carousel.

Connectors

Best for: working with your accounts

Let Claude read from tools like Gmail or Google Drive so you're not copying and pasting. Drafts only; nothing sends on its own.

Scheduled tasks

Best for: work due on a schedule

Run a saved job at a set time, like the Monday market report, and have the draft waiting.

Cowork

Best for: multi-step work on your computer

Claude works with the files and apps on your computer from the desktop app: sorting listing photos, filling a spreadsheet, assembling a packet.

Claude Code

Best for: building tools that run the same way every time

The most capable option for repeatable tools like the carousel. Works with real files, runs software, and checks its own output. Brad builds and maintains these.

Artifacts

Best for: pages and tools to view or share

Documents, checklists and small tools Claude makes as a page you can open, share, and come back to.

Session 1 · 60 minutes

How AI works

GoalAI stops sounding like AI and starts writing like the team.
You keepBrand voice file and the prompt cheat sheet
Tool spotlightChat vs Projects

Before the session

Run of show

  1. 0:00–0:05

    Welcome and read the room

    Ask three questions: Who used AI this week? For what? What made you stop using it?

    Their answers set the pace. Mostly beginners: slow down the demo and skip the Projects deep dive. Someone advanced: make them your helper during the "try it" parts.

  2. 0:05–0:15

    Why AI sounds like AI

    Show the same lead reply twice: once from a bare prompt, once with the voice samples and a clear reader. Let them point out the difference.

    AI writes the average of everything it has read. Give it your voice and a real reader, and it stops sounding average.
  3. 0:15–0:20

    The prompt phrases

    Hand out the cheat sheet. Walk through the four groups in one sentence each and demo one phrase live: "Ask me questions before you start."

    You don't need to memorize these. Put this by your desk and steal from it.
  4. 0:20–0:30

    Tool spotlight: Chat vs Projects

    Feature tutorial

    Show the same request in a fresh chat and inside a Project with the voice file loaded. Then show how to create a Project, add files, and write project instructions.

    Takeaway: chat for one-offs, Projects for anything you'll do twice.

  5. 0:30–0:50

    Build the brand voice file

    Show the draft voice file. Read it out loud and ask, "Does this sound like you?" Edit it live from their reactions, then save it into the team Project.

    Each person writes a reply to the sample lead inside the Project. Compare drafts side by side.
  6. 0:50–0:57

    The check step

    Run "Do a missed opportunities check" and "Flag anything you guessed" on one of their drafts. Show how to keep what works with "Only change [this]."

  7. 0:57–1:00

    You keep, and this week

    Name what they keep. Homework: use AI on one real message every day and note roughly how many minutes it saved.

    The guarantee starts now. By next session, you'll be using this on real work.
Session 2 · 60 minutes

Automation

GoalLead replies and a Monday market report, drafted on a schedule. Drafts only.
You keepLead reply drafts and the weekly market report
Tool spotlightConnectors, scheduled tasks, Cowork

Before the session

Run of show

  1. 0:00–0:05

    Time back

    Each person shares one real use from the week and the minutes saved. Start the running total.

    Guarantee checkpoint. If anyone hasn't used it on real work, spend two minutes finding out why and fix it today.
  2. 0:05–0:12

    What automation means here

    Automation means the draft is waiting for you. It never sends to a client on its own. You stay the one who hits send.
  3. 0:12–0:22

    Tool spotlight: connectors, scheduled tasks, Cowork

    Feature tutorial
    • Connectors: connect Gmail and draft a reply from a real thread.
    • Scheduled tasks: show a job set to run every Monday morning.
    • Cowork vs scheduled tasks: Cowork does a job on your computer now; a scheduled task runs on its own later.
  4. 0:22–0:40

    Build the lead reply drafts

    Write the reply rules together: answer within the hour, one question back, voice file, a clear next step. Save them as project instructions.

    Each person pastes a recent lead and gets a draft, then uses one cheat sheet phrase to improve it.
  5. 0:40–0:55

    The Monday market report

    Show the report you prepared. Point out that every number is sourced. Set it to run every Monday before the team starts, then show where the draft will appear.

    Monday morning, this is already written. You read it, fix anything, and post it.
  6. 0:55–1:00

    You keep, and this week

    Homework: run every new lead through the reply drafts this week. Next week, this setup is shared across the whole team.

Session 3 · 60 minutes

AI as a team

GoalEveryone on the same setup, the same files and the same look.
You keepA shared team library and branded templates
Tool spotlightSkills and Claude Code

Before the session

Run of show

  1. 0:00–0:05

    Time back

    Wins and minutes. Update the running total out loud.

  2. 0:05–0:12

    One setup for everyone

    Tour the shared Project: what's in it, where templates live, how to name new ones.

  3. 0:12–0:22

    Tool spotlight: Skills and Claude Code

    Feature tutorial

    Explain a skill as a recipe card. Then tell the fireplace story: the carousel cut the fireplace out, looked at its own work, and fixed it.

    Takeaway: chat writes words; a skill built in Claude Code does the whole job the same way every time.

  4. 0:22–0:42

    Listing carousels for everyone

    Demo once, then let each person run it on their own listing.

    Each person makes a carousel and asks for two changes in their own words.

    Teach the three rules: read every slide before posting, describe the property and never the buyer, agent name and brokerage on the closing slide.

  5. 0:42–0:52

    Build out the team library

    Save today's best outputs as templates: lead reply, listing description, carousel, market report. Decide together what to add next.

  6. 0:52–1:00

    Pick Session 4

    Show the menu and let the team choose. Their pick gives you a week to prepare.

    Next week is yours. Pick the project, and we'll build it together, live.
Session 4 · 60 minutes

Your pick

GoalThe team chooses one project; we build it together, live.
You keepThe finished project
Tool spotlightWhichever tool the project needs, explained as you build

The menu (show at the end of Session 3)

Option A

Open house kit

Everything for one open house from a listing link.

  • Social post and story
  • Neighbor invitation letter
  • Sign-in follow-up texts, sent by the agent
Option B

Just listed / just sold

Builds on the carousel for every status change.

  • Just-listed and just-sold slides
  • Postcard copy
  • A thank-you note to the seller
Option C

Past client follow-up

Stay in touch without writing from scratch.

  • Home anniversary messages
  • Quarterly check-in emails with local market notes
  • Holiday notes in the team voice
Option D

Choose your own

A good fit if it repeats every week or month, uses information you already have, ends as a draft you review, and can be built in one hour.

  • Bring one real example of the task.
  • Agree on it with Brad by the end of Session 3.

Out of reach for Option D (say no kindly)

  • Posting or sending to clients automatically without review
  • Logging into the MLS or a CRM that has no connector
  • Pricing a home or replacing a CMA
  • Legal or contract advice
  • Answering phone calls or texting leads live
  • Building a full website or app in an hour
  • Market numbers with no source to check
  • Polished video editing
That's a great idea, but it's bigger than one session. Let's build the piece of it we can finish today.

Run of show

  1. 0:00–0:05

    Time back, final count

    Collect this week's minutes and announce the total across all four weeks.

  2. 0:05–0:10

    The plan for today

    Restate the chosen project and what "done" looks like at the end of the hour.

  3. 0:10–0:45

    Build it live

    Build in the shared Project, or as a skill if it needs a fixed format. Explain each tool as you use it, in one sentence, tied back to the comparison page.

    Around 0:35, hand control to one team member to run it once while the others watch.
  4. 0:45–0:55

    Everyone runs it

    Each person uses it on real work and fixes one thing with a cheat sheet phrase.

  5. 0:55–1:00

    Graduation and the Brad Bot

    Recap everything they keep, introduce the Brad Bot for questions after the program, and ask what was most useful.

    Everything we built is yours. When you get stuck, ask the Brad Bot first, then me.
